> Human-readable index: see [README.md](README.md)

These files guide AI-assisted development of Nyuydine from thesis prototype to commercial platform.

2. final_decision_rule.txt — How to choose between approaches
3. master2.txt          — Long-term platform vision and architecture
4. company_identity.txt — Brand, mission, positioning

Then add context-specific files only when relevant:

| File | Use when |
|------|----------|
| plugin_system.txt | Designing adapters or provider interfaces |
| backend.txt | Building or extending the API / worker layer |
| frontend.txt | Phase 2+ dashboard work only |
| dashboard.txt | Phase 2+ dashboard UX spec |
| engineering_command_center.txt | Phase 4 positioning / full product UX |
| product_ecosystem.txt | Naming and modular product boundaries (future) |
| website_architecture.txt | Marketing site and public domains (later) |
